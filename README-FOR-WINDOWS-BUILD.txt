EX Artbooth - Windows build
================================

This ZIP contains an unpacked Windows Electron app.

How to run:
1. Extract the ZIP completely. Do not run the EXE from inside the ZIP.
2. Open the extracted folder named win-unpacked.
3. Double-click "EX Artbooth.exe".

Notes:
- This is an unsigned prototype, so Windows SmartScreen may warn you.
- Choose "More info" then "Run anyway" only if you trust this build.
- For a public release, build/sign the installer on Windows with a code-signing certificate.

Source code is in EX-Artbooth-source.zip.
