App icon sources for EX Artbooth.

icon.ico        - multi-size Windows icon (16-256 px), used for EX Artbooth.exe and installers
icon.png        - 512x512 master, also copied to app/icon.png for the in-app logo
icon-source.png - original artwork

This folder is named "appicons" rather than the electron-builder default "build"
because folders named "build" are treated as disposable output and can be cleaned away.
